# MergeMind
Smart MR review assistant

MergeMind uses AI to support the Merge Request review process by automatically analysing code changes and providing meaningful review feedback before merging.

It can help identify potential bugs, code quality issues, security concerns, missing test coverage, and possible impacts on existing functionality. It can also summarise the changes in an MR and highlight areas that require reviewer attention.

The goal is to reduce manual review effort, improve review consistency, and help developers identify issues earlier, while keeping the final review and approval decision with the developer/reviewer.
